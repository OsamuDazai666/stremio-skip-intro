Skip intros in Stremio.

Netflix-style Skip Intro and Next Episode buttons for the Stremio app on Windows, macOS and Android. Made for anime, and it works for any series that has timestamps on AniSkip or TheIntroDB.

Install

About a minute, start to finish.

  1. Copy the command

    Use the yellow button above, or download install.bat instead.

  2. Paste it in Terminal

    Press Win + X, open Terminal, paste with Ctrl + V and press Enter.

  3. Click Yes

    Windows asks for permission once. Stremio restarts, and your next opening has a Skip Intro button.

  1. Copy the command

    The installer opens it for you. From now on, start Stremio with this app, and keep it in your Dock.

Where it works

Tested on real machines with real episodes. Last checked November 2026.

WindowsWorks

Stremio for Windows (v5). Tested on Windows 10 with Stremio's own player.

macOSWorks

The official Stremio for Mac (5.1). Tested on macOS 27, Apple Silicon. Intel Macs get the same build, but it hasn't been tested on one yet.

Android phonesWorks

Stremio for Android 2.6.1, patched with Morphe Manager. Tested on Android 16. Newer Stremio versions are marked experimental until checked.

Linux, Android TV, iOSNot yet

On Linux, the plugin works in Stremio Enhanced. For Android TV, try the community stremio-morphe-patches. Nothing for iOS yet.

Questions

What it changes, how to remove it, and why it isn't a regular addon.

Why isn't this a one-click Stremio addon?

Stremio addons can only provide catalogs, streams and subtitles. They can't put a button on the player or move the video forward. So this is a small plugin that runs inside the Stremio app's page instead, and the installer sets that up.

What does the installer change on my computer?

Windows:

  • It copies the plugin to %LOCALAPPDATA%\StremioSkipIntro.
  • It adds one Windows setting that only affects Stremio. This is what the "Yes" prompt is for. It lets the plugin connect to Stremio through 127.0.0.1:9334, which only programs on your own PC can reach.
  • It adds a hidden "Stremio Skip Intro" helper to your Startup folder. When Stremio is open, the helper adds the plugin, and it fetches updates from this project's GitHub.

macOS:

  • It copies the plugin and a small helper library to ~/Library/Application Support/StremioSkipIntro.
  • It creates a Stremio Skip Intro app. That app opens the official Stremio with the helper loaded (which Stremio's own code signature allows), and the helper adds the plugin to Stremio's page. It also fetches plugin updates.

On both, Stremio itself isn't modified. It still loads web.stremio.com and plays everything through its own player.

Android: Morphe Manager rebuilds the Stremio app with the Skip Intro patch and installs it in place of yours. The patch adds the timestamp lookup and the buttons to Stremio's player, and nothing else. Stremio Premium features stay Premium.

Does it work for anime?

That's what it was built for. It matches Stremio's episode IDs (IMDb, Kitsu or MyAnimeList) to the right MyAnimeList entry, including split seasons and long shows numbered straight through, like One Piece. AniSkip provides the opening and ending times, and TheIntroDB fills in recaps, credits and previews.

No button showed up for my episode

That episode doesn't have timestamps on AniSkip or TheIntroDB yet. Anyone can submit them on those sites, and once they're added, everyone gets the button.

How do I uninstall it?

Windows: paste this in Terminal and click Yes:

PS>irm https://osamudazai666.github.io/stremio-skip-intro/uninstall.ps1 | iex

macOS: paste this in Terminal:

%curl -fsSL https://osamudazai666.github.io/stremio-skip-intro/uninstall-mac.sh | bash

Android: uninstall the patched Stremio and install Stremio again from Google Play.

Why do I open "Stremio Skip Intro" on a Mac instead of Stremio?

The helper can only be added when Stremio starts. The Stremio Skip Intro app starts Stremio with it (and restarts Stremio if it was already open without it). If you open Stremio the usual way, it works as normal, just without the skip buttons.

Linux or Android TV?

Not from this project yet. On Linux, the same plugin works in Stremio Enhanced: copy skip-intro.plugin.js into its plugins folder. For Android TV, the community stremio-morphe-patches project adds skip buttons to Stremio's TV player.
