FAQ

Why isn't this a normal one-click Stremio addon?

Stremio addons can only provide catalogs, streams and subtitles. They can't put a button on the player or seek the video. So this is a small plugin that runs inside the Stremio app's page instead, and the installer sets that up.

What exactly does the installer change?
  • Copies the plugin to %LOCALAPPDATA%\StremioSkipIntro.
  • Adds one Stremio-only WebView2 setting (needs the admin "Yes"). It opens a debugging port on 127.0.0.1:9334, which only programs on your own PC can reach, so the plugin can be added to Stremio's page.
  • Adds a hidden "Stremio Skip Intro" helper to your Startup folder. When Stremio is open, the helper adds the plugin.

Stremio itself isn't modified. It still loads web.stremio.com and plays everything through its own mpv player.

Does it work for anime?

Yes, anime comes first. The plugin maps Stremio's IMDb, Kitsu and MAL episode IDs to MyAnimeList entries, including split seasons and absolute numbering (e.g. One Piece). It then asks AniSkip for the opening and ending times, and TheIntroDB fills in recaps, credits and previews.

No button showed up for my episode

Nobody has submitted timestamps for that episode yet. The plugin only skips where AniSkip or TheIntroDB have data. You can add timestamps on those sites, and everyone benefits.

Mac, Linux, Android TV?

Not yet. The installer targets the Windows desktop app. On other desktops, the same plugin works in Stremio Enhanced (copy skip-intro.plugin.js into its plugins folder).
